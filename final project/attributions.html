PROJECT INFORMATION

Attributions & disclaimer.

Information about the sources, scope, and limitations of this student project.

Project purpose

AutoHub is an educational frontend project demonstrating responsive design, JSON data integration, JavaScript array methods, ES modules, local storage, dialogs, and URL query parameters.

Data and accuracy

The included dataset is illustrative and manually authored for demonstration. Vehicle descriptions and part compatibility notes are general educational summaries, not official specifications. Verify all specifications and fitment with the vehicle manufacturer or a qualified parts professional.

Visual assets

The home-page vehicle artwork is an original inline SVG illustration created for this project. The interface uses CSS-generated shapes and typography rather than third-party product photos.

External services

No external API is required for the project to run. This keeps the directory reliable for classroom demonstrations and allows the asynchronous JSON fetch to be shown locally.
